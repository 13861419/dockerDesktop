# 首次启动向导（Onboarding Wizard）设计文档

- 日期：2026-09-20
- 状态：已批准（方案 A）
- 目标版本：1.88.0

## 背景与目标

产品当前增长目标是拉新——重点是**从 1Panel / 宝塔 / Portainer 迁移过来的用户**。这类用户不迁移的最大障碍被判定为**首装上手体验**：装完面板看到一堆功能，但不知道从哪开始、自己的业务在哪里。

本设计以单点突破方式解决「装完不知道干嘛」：一个四步首装向导 + 列表页空状态引导，让迁移用户在第一分钟看到「我的东西都在这里」。

**明确不做**（YAGNI）：解析 1Panel / 宝塔私有配置文件做自动导入（脆弱、成本高）；独立官网/对比页。

## 触发与状态

- **触发**：管理员登录后，检查全局设置键 `onboarding_done`；值为 `'0'`（待完成）→ 跳转全屏向导路由 `/onboarding`。
- **全新安装判定**：storage 初始化时若 `users` 表为空（首次初始化，创建 admin 前）→ 写入 `onboarding_done='0'`；存量库升级无此键 = 视为已完成，**不受打扰**。
- **完成标记**：向导走完或点击「跳过」→ `PUT /api/settings/onboarding_done`（值为 `'1'`）。全局键（非每用户），首个管理员走完即全员生效。
- **重开入口**：设置页新增「重看首装向导」按钮（将标记重置为 `'0'` 并跳转向导）。
- **中断恢复**：向导为独立路由，每步独立调用 API 且即时生效，刷新/离开后重新进入即可继续；无向导内暂存状态。

## 四步流程

### ① 欢迎与安全

- 面板核心能力一屏速览（监控 / 容器 / Compose / 告警 / 自动化）。
- **改默认密码强提醒**：当前登录用户名为 `admin` 时显示醒目提醒卡 +「立即改密」按钮（不探测密码本身，仅按用户名判定）；可跳过但全程可见。
- 复用：现有改密接口与改密弹窗。

### ② 纳管本机环境

- 并行拉取：容器列表、镜像数量、外部 Compose 项目（`discoverExternalProjects` 已有能力）。
- 展示摘要：「发现 N 个容器、M 个镜像、K 个编排项目」；外部项目 1.50.0 起已自动纳管，此处仅展示摘要与跳转链接，无显式导入动作。
- 失败降级：Docker 未就绪时该步显示「暂未检测到 Docker，可跳过，稍后在总览查看」，不阻塞。

### ③ 可选配置

- 镜像加速源：默认预填国内可搜索源（轩辕），一键保存（`hubConfig` 现有逻辑）。
- 通知渠道：可跳过，表单逻辑从告警渠道页抽用。
- 两项均为可跳过的可选步骤。

### ④ 迁移对照与下一步

- **概念对照表**（竞品迁移心智）：
  | 1Panel / 宝塔 | 本面板 |
  |---|---|
  | 网站 / 反向代理 | 站点反代 + SSL 证书 |
  | 应用商店 | 应用商店（AppStore） |
  | 计划任务 | 计划任务 |
  | 防火墙 | 防火墙（Windows）/ 端口地图 |
  | —（独有） | Edge 多节点管理 |
  | —（独有） | Git 仓库自动部署 / CI 门禁 |
  | —（独有） | 高危操作审批流 |
- **三张推荐卡**：「装个应用试试」→ AppStore；「绑 Git 仓库自动部署」→ Git 部署页；「加一台 Edge 节点」→ Edge 页。

## 空状态 CTA

容器 / 镜像 / Compose 三个列表页空态从纯文字改为引导按钮：

- 容器空态 →「拉取一个镜像试试」直达拉取弹窗；
- 镜像空态 →「从镜像源拉取」直达拉取；
- Compose 空态 →「新建编排 / 纳管外部项目」。

## 边界与错误处理

| 场景 | 行为 |
|---|---|
| Docker 未就绪 / 扫描失败 | 步骤内降级提示 + 跳过，向导不阻塞 |
| 非管理员登录 | 不弹向导（仅管理员可见） |
| 存量库升级 | `onboarding_done` 缺省 = 已完成，不弹 |
| 向导中跳过 | 直接写完成标记，四步独立生效、已完成的部分保留 |

## 测试与验收

- 单测（server/test）：`onboarding_done` 设置键读写契约；外部项目发现接口契约（沿用现有测试基建与临时数据目录模式）。
- E2E 冒烟：新库登录 → 向导出现 → 跳过 → 再登录不再出现。
- 验收标准：全新安装后首登必弹；走完/跳过后不再弹；总览能正常显示已纳管环境。
